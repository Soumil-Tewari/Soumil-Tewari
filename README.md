👋 Hey, I'm Soumil

I'm a Computer Science student at VIT Vellore and a developer who enjoys taking products all the way from an idea to something people can actually install, use and rely on.

My favourite kind of project is not a tutorial clone.

It's the one where I have to figure out:

frontend → backend → database → infrastructure → deployment → users

I've been building software since 2021, starting with Android applications and gradually moving into full-stack systems, developer tools, Windows applications, cloud infrastructure and AI-powered products.

I don't just like writing code. I like shipping software.
