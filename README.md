# Hey, I'm Soumil 👋

I'm a Computer Science student at **VIT Vellore** who likes taking an idea from *"this could be useful"* to an actual application that people can install and use.

I don't particularly enjoy building projects that only live inside a folder called `final_final_v2`.

I like shipping.

I have built across **Android, React Native, web, Windows, backend systems, databases, cloud infrastructure and AI**, and I enjoy going all the way down the stack when a project needs it.

Currently studying **Computer Science & Engineering at VIT Vellore**, while building products, experimenting with new ideas, and slowly figuring out which rabbit hole to fall into next.

# 🚀 Things I've Built

## 📓 Cahier

**Full-stack LaTeX IDE + Windows Desktop Application**

A serious attempt at building a proper LaTeX development environment rather than just another text editor.

**Stack**

`React` `TypeScript` `Monaco Editor` `Node.js` `BullMQ` `Redis` `Docker` `XeLaTeX` `Socket.IO` `WinUI 3` `C#` `WebView2` `Oracle Cloud`

### What went into it

* Full multi-file code editor
* Monaco Editor integration
* Persistent tabs
* File tree
* Drag & drop
* IndexedDB persistence
* PDF and media previews
* Integrated compilation terminal
* ZIP export
* Distributed compilation backend
* Dockerized XeLaTeX compilation
* BullMQ + Redis job processing
* Real-time compiler logs through Socket.IO
* Native Windows integration through WebView2
* Custom title-bar integration
* Theme synchronization
* Production cloud deployment
* MSIX packaging
* Microsoft Store release

This one taught me something important:

**Building software gets a lot more interesting once the happy path stops working.**

## 📈 Quantaroo

**AI-powered stock market insights app**

Built for Android and shipped to both the **Google Play Store** and **Samsung Galaxy Store**.

Quantaroo combines market data, interactive charts, financial news and AI-generated summaries into one mobile experience.

**Stack**

`React Native` `FastAPI` `Python` `PostgreSQL` `Firebase` `Gemini SDK` `Docker` `GitHub Actions` `Oracle Cloud`

### Built around

* Interactive market charts
* Stock analytics
* Financial news aggregation
* AI-generated news summaries
* Market trend analysis
* Scheduled data processing
* Push notifications
* Firebase authentication
* PostgreSQL data storage
* Containerized backend
* Automated jobs
* Cloud deployment
* AdMob monetization

The interesting part wasn't making another stock app.

It was making **the whole pipeline work**.

Data → processing → backend → database → mobile client → notifications → users.

# ☁️ I like going beyond the frontend

One of my favourite parts of building projects is making the pieces actually talk to each other.

```text
                    ┌─────────────────┐
                    │   Mobile / Web  │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │    REST APIs    │
                    └────────┬────────┘
                             │
                  ┌──────────┴──────────┐
                  ▼                     ▼
          ┌──────────────┐      ┌──────────────┐
          │   Backend    │      │ Background   │
          │ Node/FastAPI │      │    Jobs      │
          └──────┬───────┘      └──────┬───────┘
                 │                     │
                 ▼                     ▼
          ┌──────────────┐      ┌──────────────┐
          │ PostgreSQL   │      │ Redis/Queue  │
          └──────────────┘      └──────────────┘
                 │
                 ▼
          ┌──────────────┐
          │ Cloud / Docker│
          └──────────────┘
```

I have deployed actual applications using:

`Docker` `Nginx` `Linux` `HTTPS` `DNS` `Redis` `BullMQ` `GitHub Actions` `Oracle Cloud`

Because eventually every developer discovers the same ancient truth:

> localhost is not production.
