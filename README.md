## About

I'm a Computer Science student at **VIT Vellore** who takes ideas from *"this could be useful"* to shipped applications people actually install. Started building seriously in 2021 — since then I've moved from Android apps to full-stack products, cloud backends, native Windows apps, and developer tools.

I like going all the way down the stack: design → code → database → backend → cloud → deployment → users → debug → ship again.
